# Projects

Nine repos, five languages. Full ledger with live telemetry lives at [George Lab](/) on the site; machine-readable snapshots are linked at the bottom.

| # | Project | Language | What it is |
|---|---------|----------|------------|
| 01 | [agent-mesh](https://github.com/georgenijo/agent-mesh) | Go | Agents orchestrating themselves: presence, file claims, async questions, a shared blackboard. Claude Code, Codex, and Cursor acting like one team. |
| 02 | [usher](https://github.com/georgenijo/usher) | Go | MCP broker: a single MCP endpoint that routes, trims, arbitrates, and audits tool calls across a fleet of servers. |
| 03 | [hangar](https://github.com/georgenijo/hangar) | Rust | Agent control plane: scheduling, budgets, kill switches, and an audit log for long-lived coding agents. |
| 04 | [ghosthands](https://github.com/georgenijo/ghosthands) | Python | Local computer-use for macOS: a local model reads the screen and drives native apps through the accessibility tree. Nothing leaves the machine. |
| 05 | [murmur-app](https://github.com/georgenijo/murmur-app) | Rust | Local voice-to-text for macOS: hold a key, speak, release. Whisper on the GPU, fully offline. |
| 06 | [fleetmap](https://github.com/georgenijo/fleetmap) | Swift | Live map of what your Mac runs: every process a node, sized by RAM, colored by CPU, wired by real sockets. |
| 07 | [gauge](https://github.com/georgenijo/gauge) | Swift | Claude usage in the menu bar: session and weekly limits, pace until reset, spend from local logs. |
| 08 | [whoop-dashboard](https://github.com/georgenijo/whoop-dashboard) | TypeScript | Health analytics with an AI coach that reads months of WHOOP trends. |
| 09 | [aperture](https://github.com/georgenijo/aperture) | Swift | iOS film camera: fixed stocks, 36 exposures, no preview until the roll is developed. |
