# About

George Nijo is a software engineer in Boston. Supervisor of agents.

He builds infrastructure for AI agents: coordination meshes, MCP brokers, and control planes — the plumbing that keeps a fleet of agents fast, cheap, and accountable. Currently building AgentOS, a personal + home agent operating system.

Principles:

- Local-first: build tools that solve your own problems on your own machine.
- Honesty-first: then open-source the parts worth sharing.
- Ship the menu bar app before the platform.

Languages: Python, Go, Rust, Swift, and a dash of TypeScript.
