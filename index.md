# George Nijo

Software engineer in Boston building infrastructure for AI agents: coordination meshes, MCP brokers, and control planes — the plumbing that keeps a fleet of agents fast, cheap, and accountable. Currently building AgentOS, a personal + home agent operating system.

Local-first, honesty-first: build tools that solve your own problems on your own machine, then open-source the parts worth sharing. Ship the menu bar app before the platform.

Languages: Python · Go · Rust · Swift · a dash of TypeScript.

## Projects

- [agent-mesh](https://github.com/georgenijo/agent-mesh) (Go) — agents orchestrating themselves: presence, file claims, async questions, a shared blackboard.
- [usher](https://github.com/georgenijo/usher) (Go) — MCP broker: one endpoint that routes, trims, arbitrates, and audits tool calls across a fleet of servers.
- [hangar](https://github.com/georgenijo/hangar) (Rust) — agent control plane: scheduling, budgets, kill switches, audit logs for long-lived coding agents.
- [ghosthands](https://github.com/georgenijo/ghosthands) (Python) — local computer-use for macOS through the accessibility tree; nothing leaves the machine.
- [murmur-app](https://github.com/georgenijo/murmur-app) (Rust) — local voice-to-text for macOS: Whisper on the GPU, fully offline.
- [fleetmap](https://github.com/georgenijo/fleetmap) (Swift) — live map of every process on your Mac, wired by its real sockets.
- [gauge](https://github.com/georgenijo/gauge) (Swift) — Claude usage in the menu bar: limits, pace until reset, spend.
- [whoop-dashboard](https://github.com/georgenijo/whoop-dashboard) (TypeScript) — health analytics with an AI coach.
- [aperture](https://github.com/georgenijo/aperture) (Swift) — iOS film camera: fixed stocks, 36 exposures, no preview until developed.
