Privacy

This is a personal portfolio site. The privacy story is deliberately boring:

  • No analytics, no telemetry, no tracking pixels.
  • No cookies, no login, no forms — nothing here can submit personal data.
  • No ads and no third-party embeds.
  • No JavaScript is required to read any page's content.

Data published here

The site publishes only project telemetry George chooses to share: public GitHub repository stats (releases, open issues, pull requests, activity dates) in lab-projects.json, and a short-lived, privacy-safe fleet health snapshot (fleet-health.json) collected from machines he owns. Neither contains visitor data — there are no visitors to track.

Infrastructure

The site is served as static files. Standard server logs may be kept briefly by the hosting provider for security and abuse prevention; they are not used for profiling or advertising.
